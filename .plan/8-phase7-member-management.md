# フェーズ 7: 担当者の管理

- 全体プラン: [1-gantt-chart-mvp.md](1-gantt-chart-mvp.md)
- 担当: Sonnet 5.5
- ブランチ: `feat/gantt-member-management`
- 前提: フェーズ 6 が完了している（`ConfirmDialog` を使うため）

## 目的

担当者の追加・名前変更・並び替え・削除を画面から行えるようにする。

## 作業内容

### 1. フック

- `useMembers` に `createMember` / `renameMember` / `reorderMembers` / `deleteMember` を足す
- 担当者を削除したときは、repository が配下の案件も削除する。画面側では `useProjects` の一覧も読み込み直す（`useGanttPage` で 2 つのフックをつなぐ）
- 削除した担当者の案件をサイドパネルで編集中だった場合は、パネルを閉じる

### 2. コンポーネント

- `MemberManageDialog`: リスト最下部の「担当者を管理」ボタンで開くダイアログ（`<dialog>`）
  - 一覧: 名前（その場で編集できる入力欄）/ 上へ・下へボタン / 削除ボタン / 担当している案件の数
  - 最下部に新しい担当者の入力欄と「追加」ボタン
- 並び替えは上へ・下へボタンで行う（ドラッグでの並び替えはスコープ外。帯のドラッグと操作がまぎらわしくなるため）

### 3. バリデーションと確認

- 名前: 必須（前後の空白は除く）、最大 50 文字。同じ名前は警告だけ出して登録は許す（同姓の人がいる場合のため）
- 削除: 案件を持つ担当者のときは「案件 N 件も一緒に削除されます」と確認ダイアログに表示する

## 完了条件

- [ ] 担当者を追加すると、左のリストに表示され、サイドパネルの担当者の選択肢にも出る
- [ ] 名前の変更と並び替えが左のリストに反映される
- [ ] 案件を持つ担当者を削除すると、配下の案件も消える
- [ ] 再読み込みしても内容が残る
- [ ] `pnpm lint` / `pnpm typecheck` / `pnpm test` / `pnpm build` が成功する
