# フェーズ 5: 画面の骨組み（リストとタイムライン）

- 全体プラン: [1-gantt-chart-mvp.md](1-gantt-chart-mvp.md)（1 章「画面仕様」）
- 担当: Sonnet 5.5
- ブランチ: `feat/gantt-layout`
- 前提: フェーズ 3・4 が完了している

## 目的

保存済みのデータを読み込んで、左のリストと右のタイムラインに表示する。操作（追加・編集・ドラッグ）はまだ作らず、見た目と表示のロジックを固める。

## 作業内容

### 1. ページの構成

- `src/app/page.tsx`（Server Component）: `<GanttChart />` を置くだけ
- `GanttChart.tsx`（Client Component、`"use client"`）: `useGanttPage` から状態を受け取り、各コンポーネントに渡す
- localStorage はブラウザでしか読めないため、読み込みが終わるまでは読み込み中の表示を出す（サーバー側のレンダリングとの不一致を防ぐ）
  - `cacheComponents` が有効なので、Client Component の置き方と `Suspense` の要否を `node_modules/next/dist/docs/` で確認してから決める

### 2. フック

| フック | 責務 |
| --- | --- |
| `useGanttPage` | 下のフックを束ね、画面に必要な値と操作をグループ化して返す |
| `useMembers` | 担当者の一覧の読み込みと保持（追加・編集はフェーズ 7 で足す） |
| `useProjects` | 案件の一覧の読み込みと保持（追加・編集はフェーズ 6 で足す） |
| `useTimelineRange` | 用意する日付の範囲（開始日と日数）。端に近づいたら広げる（無限スクロール） |
| `useTimelineScroll` | スクロール位置の制御（端での範囲の拡張、◀ / ▶ / 今日のスクロール、画面左端の日付） |
| `useCollapsedMembers` | 折りたたみ中の担当者 ID の集合。開閉の切り替え |

- `useMembers` / `useProjects` は `createGanttRepository()` で作った repository を使う。repository はコンポーネントの外で 1 回だけ作る
- 担当者ごとの案件のまとまり（`memberId` で分類し、開始日順に並べたもの）は state にせず、`members` と `projects` から計算する

### 3. コンポーネント

| コンポーネント | 内容 |
| --- | --- |
| `GanttHeader` | タイトル、スクロールのボタン（◀ / 今日 / ▶）、表示中の年月 |
| `MemberList` | 左のリスト。担当者行（▼/▶ で折りたたみ、配下の案件数）と案件行。最下部に「案件を追加」「担当者を管理」ボタン（押したときの処理はフェーズ 6・7） |
| `Timeline` | 右側のスクロール領域。日付ヘッダーを上に固定する |
| `TimelineDateHeader` | 月の行と日の行の 2 段。土日祝は文字色を変え、祝日名を `title` で出す |
| `TimelineGrid` | 背景の縦線。土日祝の列に背景色を付ける |
| `TodayLine` | 今日の列に縦線 |
| `ProjectBar` | 案件の帯（案件名を中に表示。入りきらない場合は省略記号）。はみ出している側は角を丸めない |
| `MemberSummaryBar` | 担当者行に、配下の案件を細い帯でまとめて表示する（折りたたみ中でも予定が分かるように） |

### 4. スクロールの同期

- 左のリストと右のタイムラインは、**1 つの縦スクロール領域**の中に左右に並べる（2 つの領域のスクロール位置を JavaScript で合わせるより、ずれが起きにくいため）
- 左のリストは `position: sticky; left: 0` で横スクロールしても残す。日付ヘッダーは `position: sticky; top: 0`
- 行の高さは定数（`MEMBER_ROW_HEIGHT` / `PROJECT_ROW_HEIGHT`）で左右を揃える

### 5. 空の状態

- 担当者が 0 人のとき: 「まず担当者を追加してください」と「担当者を管理」ボタンを出す
- 担当者に案件が 0 件のとき: 担当者行だけを出す

### 6. 動作確認用のデータ

- 開発中だけ使える「サンプルデータを入れる」処理を用意する（例: `src/features/gantt/devSeed.ts`。本番ビルドではボタンを出さない）
- 月またぎ・表示期間外・1 日だけの案件を含める
