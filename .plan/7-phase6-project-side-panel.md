# フェーズ 6: サイドパネル（案件の追加・編集・削除）

- 全体プラン: [1-gantt-chart-mvp.md](1-gantt-chart-mvp.md)
- 担当: Sonnet 5.5
- ブランチ: `feat/gantt-side-panel`
- 前提: フェーズ 5 が完了している

## 目的

帯のクリック、またはリスト最下部の「案件を追加」ボタンで右側にサイドパネルを開き、案件を追加・編集・削除できるようにする。

## 作業内容

### 1. フック

- `useSidePanel`: パネルの状態を 1 つの state で持つ
  ```ts
  type TSidePanelState =
    | { mode: "closed" }
    | { mode: "create"; defaultMemberId: string | null }
    | { mode: "edit"; projectId: string }
  ```
  - 編集中の案件そのものは state に持たず、`projectId` から `projects` を引いて求める（データと表示がずれないため）
  - 担当者行で「案件を追加」したときは、その担当者を初期選択にする（任意。リスト最下部のボタンでは未選択）
- `useProjects` に `createProject` / `updateProject` / `deleteProject` を足す。保存が成功してから state を更新する
- `useProjectForm`（`components/hooks/` 配下、パネル専用）: 入力値、バリデーション結果、送信処理

### 2. コンポーネント

- `ProjectSidePanel`: 右からスライドして出るパネル。タイムラインの上に重ねる（タイムラインの幅は変えない）
  - 入力項目: 担当者（`select`）/ 案件名 / 開始日・終了日（`input type="date"`）/ 帯の色（プリセットから選ぶ）/ メモ（`textarea`）
  - ボタン: 保存 / キャンセル / 削除（編集時のみ）
- `ConfirmDialog`: 削除の確認。`<dialog>` 要素を使う（フェーズ 7 でも使う）

### 3. バリデーション

- 案件名: 必須（前後の空白は除く）、最大 100 文字
- 担当者: 必須（担当者が 0 人のときは追加ボタン自体を押せないようにし、理由を表示する）
- 開始日 ≦ 終了日
- エラーは各項目の下に表示し、保存ボタンを押したときにまとめて検証する

### 4. 操作性

- `Esc` キーでパネルを閉じる。入力途中で閉じるときは確認しない（身内利用でシンプルさを優先。必要ならあとで追加）
- 開いたときに案件名の入力欄にフォーカスする
- 編集中の帯を強調表示する
- 保存に失敗したときはパネル内にエラーを表示し、パネルは閉じない

## 完了条件
