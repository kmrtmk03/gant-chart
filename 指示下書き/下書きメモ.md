# このプロジェクトではシンプルなガントチャートのサイトを作成したいと思います。

## 以下要件

### 概要

担当者ごとにいつどの案件の作業を行なっているかを一目で見れるようにしたい。  
担当者が親、案件名が子となる構造で左側にリストとして表示される。
右側には期間の帯が表示される。
帯をクリックすると右側にサイドパネルが展開され、その案件の情報を編集できる。
もしくはリストの最下部にある追加ボタンを押すことで右側にサイドパネルが表示され、案件を追加できる

### 使用技術

- vite
- Next.js（将来的にfirebaseで管理する可能性があるので、それを考慮）
- sass
- typescript
- pwa（アクセスしやすいようにアプリとして開きたい。ローカル環境のhttps化）
- localstrage（開発用。firebaseに移行しやすいようなデータ構造で保持する）

### 使用AIエージェント

- Opus5.5（プラン作成や大規模リファクタリングなど重要な処理をする場合に使用）
- Sonnet5.5（通常の実装）
- Codex（コードレビュー、Claudeの使用制限が90%を超えるなどした場合に使用予定、モデルは適宜切り替える）
